# Prospective Customer Segmentation

A React and Tailwind CSS web page designed to present different prospective customer segments through a clean, modern card-based interface.

## 🚀 Project Overview

This project is a frontend implementation of a customer segmentation presentation design.

The page includes:

- Profile / presentation section
- Target audience heading
- Customer segmentation introduction
- Image-based customer segment cards
- Segment labels such as:
  - Engineer
  - Underserved
  - Underbanked
  - Undergraduate
- Responsive layout for different screen sizes
- Modern card styling with rounded corners and shadows

## 🛠️ Technologies Used

- React.js
- Tailwind CSS
- JavaScript
- Vite
- Lucide React Icons
